# 小红书文案生成器 v0.1

## 快速开始

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 设置 API Key
```bash
export KIMI_API_KEY="your-kimi-api-key"
```

### 3. 运行程序
```bash
python xhs_generator.py
```

## 使用示例

```
$ python xhs_generator.py
==================================================
📝 小红书文案生成器 v0.1
==================================================

请输入产品/主题：无线蓝牙耳机

选择文案风格：

3. 教程（教学分享）
```
